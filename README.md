# h2okay.github.io

Personal academic website of Jost Blasberg, served via GitHub Pages.

## Files
- `index.html` – all content (about, research, publications, contact)
- `style.css` – layout and colours (light/dark mode automatic)
- `images/profile.jpg` – portrait

## Publish
1. Create a public repository named exactly `h2okay.github.io` on GitHub.
2. Upload these files (keep the `images` folder).
3. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`.
4. After a minute the site is live at https://h2okay.github.io

## Update
Add a new paper by copying one `<li>…</li>` block in the Publications section of `index.html`.
